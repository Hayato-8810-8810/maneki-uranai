# まねき占い堂　SNS運用の手順（PCのClaudeで行う）

本人がPCのClaude（ブラウザを操作できる環境）に依頼して進める。
このファイルと CLAUDE.md を最初に読んでから作業する。

## 全体の流れ（1週間ごと）
1. **調べる**：占い系アカウントの公開投稿を見て、伸びている型を集める
2. **分析する**：時間帯・内容・フック（1行目）の傾向を表にまとめる
3. **サイトを直す**：分かったことをもとに、診断サイトの改善案を出す → 本人がOKしたものだけ直して push
4. **投稿をつくる**：Threads 7本＋Instagram 用の文章と画像
5. **本人が確認する**：投稿文の一覧を見せて、OKをもらう
6. **予約する**：Threads は1週間分をブラウザで予約。Instagram は予約か、本人が手動で投稿
7. **ふりかえる**：翌週、各投稿の表示数・いいね・コメント・リンクのクリックを本人の画面で確認し、表に残す

## 1. 調べる（他の占いアカウント）
- 見るもの：Threads・Instagram・X で「占い」「タロット」「数秘術」「オーラ」「今日の運勢」などで検索して出る、公開されている投稿
- 集める項目：投稿時刻／1行目（フック）／形式（文章だけ・画像1枚・複数枚）／問いかけの有無／反応数（見える範囲で）
- 1回の調査は20〜30投稿くらいまで。ページを大量に開き続けない
- 他人の投稿の文章・画像はそのまま使わない。「型」だけを参考にする
- ログインが必要な画面、非公開アカウント、DMは見ない

## 2. 分析のまとめ方
`docs/sns/分析/YYYY-MM-DD.md` に表で残す。
- 反応が多かった投稿の、時間帯・フックの型・形式
- まねき占い堂の3診断（数秘・魂の色・タロット）のどれに当てはめられるか
- 数字は、実際に画面で見た値だけを書く。見えなかったものは空欄（推測で埋めない）

## 3. サイトの改善
- 改善案は「どこを・なぜ・どう変えるか」を本人に見せて、OKをもらってから直す
- 直したら、スマホ幅360pxで表示と動作を確認してから main に push（Netlify が自動で反映）
- CLAUDE.md の「守ること」に反する変更はしない（エンタメ表記を消す、断定する、など）

## 4. 投稿をつくる
- 1週間分（Threads 7本）。曜日ごとに診断を回す
  - 例：月・木＝数秘／火・金＝魂の色／水・土＝タロット／日＝3つまとめて紹介
- 時間帯の目安（分析で更新する）：数秘＝昼12時台、魂の色＝夜22〜23時、タロット＝朝7〜8時
- 1行目は「自分のことかも」と思わせる問いかけか、意外な一言にする
- 最後は「何番だった？」「何色だった？」など、答えたくなる問いで終える
- Threads：ハッシュタグは本文に入れない。トピック欄に1つ。リンクは本文に入れてよい
- Instagram：ハッシュタグは5個まで。URLは押せないので「プロフィールのリンクから」
- 画像は docs/assets/ のものを使う。新しく作るときは docs/tools/ のスクリプトを参考に、サイトと同じ文章・絵柄で作る
- 作った投稿は `docs/sns/予約/YYYY-MM-DD_週.md` に、日時・本文・画像ファイル名の一覧で残す
- 本人がやっていない結果や、作り話の体験・数字は書かない

## 5〜6. 予約投稿のしかた
### Threads（ブラウザで予約できる）
- threads.com にログインした状態で、新規投稿 → 本文・画像を入れる → 右上の「…」→「日時を指定…」→ 日時を選んで予約
- 最大75日先まで。ブラウザ版では「返信」の予約はできない（リンクを返信にぶら下げたいときはアプリで本人が行う）
- 予約した投稿は「下書き」に入る。変更・削除もそこから
- 投稿・予約のボタンを押す前に、必ず本人に確認を取る

### Instagram（予約できる）
- アプリ：投稿を作る →「その他のオプション」→「この投稿を日時指定」をオン → 日時を選ぶ（公開アカウントなら最大30日先、1日25件まで）
- PCのブラウザ：Meta Business Suite（business.facebook.com）→「投稿を作成」→ Instagram を選ぶ →「日時を設定」
- 本人が手動で投稿する場合は、投稿文と画像を一式にまとめて渡す

### やらないこと
- いいね・フォロー・コメントの自動化（大量に自動で行うと、アカウントが制限される原因になる）
- 他人の投稿への自動返信
- 本人の確認なしの投稿・予約

## 7. ふりかえり
- 翌週の最初に、前の週の投稿の数字を本人の画面（インサイト）で確認し、`docs/sns/分析/` の表に足す
- 反応の良かった型を次の週に増やし、悪かった型は減らす
